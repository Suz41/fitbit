# Fit Dashboard Replica

A mobile-first HTML/CSS/TypeScript recreation of the supplied fitness dashboard screenshot.

## Run locally

```bash
npm install
npm run build
```

Then serve this folder with any static web server (for example `npx serve .`) and open `index.html`.

## Files

- `index.html` — page structure
- `styles.css` — responsive layout and visual styling
- `app.ts` — small interactions (dismiss card, add activity, navigation selection)
- `dist/app.js` — generated by the TypeScript build
